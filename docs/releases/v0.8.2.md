# InterLude 0.8.2

Documentation only: the app works exactly as 0.8.0.

## What's changed

- The README's screenshot of the web app on a computer now shows the current interface, with an earlier programme playing beside the **Skip news** switch and the day's programmes. The old one was from before the web app became InterLude's one interface.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image `ghcr.io/mstrtheplague/interlude-server:0.8.2` is the same code as 0.8.0, so there's no need to update.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.

## Download

`InterLude-0.8.2-macOS-arm64.zip` for the Mac. For the server, follow "Running the server" in the README.
