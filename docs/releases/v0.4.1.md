# InterLude 0.4.1

A new look, a phone layout that works like a music app, and a round of fixes for large text and accessibility. Nothing about how bulletins are found has changed.

## What's new

- **A new look.** The Mac panel and the web app share a dark, glass-and-gradient style. The background drifts slowly and follows what's happening: blue and violet while listening, pink through a muted bulletin, violet for an earlier programme, and on a phone the background is a single glow in the station's colour. It stands still when nothing is playing and when Reduce Motion is on.
- **"On air" on phones.** On a phone the web app is now a single player screen. The station's name is set large under a line saying what InterLude is doing, with live bars while it plays and what's on beneath. Every control sits in a dock fixed to the bottom edge: the bulletin alert with **Not news**, play and volume, and the station and speaker. Live and Earlier are tabs at the top, with Settings beside them.
- **Works with large text.** Text and controls on the web app follow the phone's text size, long names wrap instead of being cut off, volume has large quieter and louder buttons beside the slider, and tap targets are larger. Secondary text has more contrast. **Plain background** at the foot of the page turns off the gradient and blur, and the phone's Increase Contrast and Reduce Transparency settings do the same.

## Fixes

- **Mac panel:** the mute button is a real button, with a label for VoiceOver, and unmutes to the volume you had. Small labels scale with your text size. The error state is labelled. Quit is in a More menu, away from Settings. Settings keeps the long news-detection explanation behind "How news detection works".
- **Web app:** "Not news" is readable in dark mode. A stream that is starting says it takes about 20 seconds. Playback errors are in plain words and stay longer. Reset link asks you to confirm in the page. Space plays and stops. Keyboard focus is visible. If the QR code can't load, Settings says so. On a computer, the player column now stays in view beside a long programme list, as intended.
- **Server page updates:** `scripts/push-web.sh` puts a changed web page on a running server in seconds, with no image rebuild. A newer image takes over again.
- **Tidier project:** placeholder addresses replace real ones in the tests and compose file, and early experiment tools were removed.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image is `ghcr.io/mstrtheplague/interlude-server:0.4.1`. Update with `docker compose pull && docker compose up -d`.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.

## Download

`InterLude-0.4.1-macOS-arm64.zip` for the Mac. For the server, follow "Running the server" in the README.
