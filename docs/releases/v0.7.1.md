# InterLude 0.7.1

A small change: which stations start cautiously now lives in the station list rather than in code.

## What's changed

- **`"untested": true` in `stations.json`.** A station marked this way starts a new profile in shadow mode, muting only on its learned jingle, until you've checked it and turned shadow mode off in Settings. Radio 2 was already treated like this in code; it's now set in the list instead.
- **Radio 3 joins it.** Its presenters talk at length around the hour, and the speech rule hasn't been checked there. This only affects Radio 3 the first time you play it; a profile you already have keeps its settings.
- Saved station lists, on the Mac and in the server's `config` folder, pick up the flag from the bundled list.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image is `ghcr.io/mstrtheplague/interlude-server:0.7.1`. Update with `docker compose pull && docker compose up -d`.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.

## Download

`InterLude-0.7.1-macOS-arm64.zip` for the Mac. For the server, follow "Running the server" in the README.
