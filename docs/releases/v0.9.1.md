# InterLude 0.9.1

Fixes earlier programmes on the server, which 0.9.0 broke.

## Fixed

- **Earlier programmes stopped the server.** While an earlier programme starts, the page now shows how far the start has got. Working that out could build the news markings for the progress bar from a bulletin that had just opened slightly ahead of the analysis, and the server stopped and restarted instead of playing. Live radio wasn't affected. The Mac app could hit the same problem.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image is `ghcr.io/mstrtheplague/interlude-server:0.9.1`. Update with `docker compose pull && docker compose up -d`.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.

## Download

`InterLude-0.9.1-macOS-arm64.zip` for the Mac. For the server, follow "Running the server" in the README.
