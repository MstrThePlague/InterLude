# InterLude 0.8.1

Documentation only: the app works exactly as 0.8.0.

## What's changed

- The README's section on earlier programmes now says transcription runs around each of the station's bulletin minutes, which are learned per station, rather than at every :00 and :30.
- The open questions in `docs/archive/findings.md` are brought up to date: Newsbeat outside the hours recorded so far, Radio 3's speech rule and sign-off, Welsh on Radio Cymru 2, and bulletin minutes learned per minute of the hour rather than per hour of the day.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image `ghcr.io/mstrtheplague/interlude-server:0.8.1` is the same code as 0.8.0, so there's no need to update.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.

## Download

`InterLude-0.8.1-macOS-arm64.zip` for the Mac. For the server, follow "Running the server" in the README.
