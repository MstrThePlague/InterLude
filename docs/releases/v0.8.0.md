# InterLude 0.8.0

Long bulletins at fixed times, starting with Newsbeat's 15 minutes at 12:45 on Radio 1, 1Xtra and Asian Network.

## What's new

- **Long bulletins.** A station can list bulletins that run longer than usual at the same UK time every day. Radio 1, 1Xtra and Asian Network list Newsbeat at 12:45 for 15 minutes, which was played in full before.
  - InterLude listens around 12:45 as it does at :00 and :30, without listening at :45 every hour.
  - The mute may run the bulletin's length plus two minutes, instead of stopping at the usual 8 minutes.
  - Newsbeat plays clips of songs between reports, so inside a long bulletin it takes 30 seconds of music, not 5, to end the mute. The newsreader's sign-off ("your next update in half an hour") still ends it straight away; the transcriber now keeps listening for the whole bulletin.
  - A long bulletin doesn't teach the station's usual bulletin minutes or lengths.
  - Times are UK time, so they follow the clocks changing.
- On four hours of each station replayed through the speech rule, every Newsbeat was muted in full on Radio 1 and Asian Network. On 1Xtra the first 19 seconds of the 12:45 one got through. The measurements are in `docs/archive/findings.md`.

## Changes for people who build or run it

- `stations.json` gains `"longBulletins": [{"at": "12:45", "minutes": 15}]`. Saved station lists pick it up from the bundled one.
- The transcriber keeps only the last minute of a bulletin's audio, rather than all of it, so a 15-minute bulletin doesn't hold 170 MB.
- `evaluate` takes `STATION=<serviceId>` to replay with that station's long bulletins.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- Only the 12:45 Newsbeat has been checked against a recording. If you know of other long bulletins, add them to `stations.json`.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image is `ghcr.io/mstrtheplague/interlude-server:0.8.0`. Update with `docker compose pull && docker compose up -d`.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.
