# InterLude 0.6.0

Bulletins are now found by what the newsreader and presenter say on any music station, not just 6 Music, and the transcriber listens live around every bulletin time instead of only once a mute has started.

## What's new

- **Listening around every bulletin time, live.** From a minute before to three minutes after each bulletin slot, InterLude transcribes the stream as it arrives. Before, it only started listening once speech or the news theme had already started a mute.
  - The newsreader's opening ("BBC News at five thirty", "Newsbeat, I'm …") starts a mute there and then, even on a station whose news theme hasn't been learned yet.
  - A presenter's handover ("here's the news with …", "it's time for the news") starts one too, once speech has carried on for ten seconds after it. This catches a presenter talking straight into the news from before the slot, which the speech rule missed because the talk started too early.
  - Trails don't count: "after the news", "after this news", "the news is next", "news in a minute", "some good news from …".
  - If the station's theme is known and neither it nor the newsreader's opening is heard within 45 seconds, a mute started by a handover is released as presenter talk, as before.
- **Each station's own name for its news.** `stations.json` gains `newsNames`: "newsbeat" for Radio 1, "1xtra news" for 1Xtra, "6 music news" for 6 Music and "asian network news" for Asian Network. Heard at the start of a bulletin it marks the opening; heard again at the end it marks the sign-off. Wording used across the BBC ("BBC News at", "your next update", "that's the latest") works on every station. Saved station lists pick up the names.
- **Sign-offs looked for later in long bulletins.** Once a station has learned five bulletin lengths, a sign-off only counts from 60 % of its shortest usual bulletin (still at least 45 seconds), so a "next" or a station name mid-bulletin is less likely to end the mute early.

## Changes for people who build or run it

- `DetectorConfig.handoverSpeechSeconds` (10 by default) sets how much speech must follow a handover. It lives in the station profile like the other detector numbers.
- The event log gains `slotOpening` and `slotHandover` events for live listening, so a mute can be traced to the words that started it.
- Transcripts now treat `?`, `!`, `;`, `:` and quotation marks as spaces, so "5:30" reads as a time.
- On the server, whisper.cpp now runs for about four minutes around each slot, about as much as it did for a bulletin it was muting.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- The new station names are taken from how those stations' news is usually introduced, but only 6 Music's have been checked against recordings so far. Radio 2 still starts in shadow mode and mutes only on its theme.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image is `ghcr.io/mstrtheplague/interlude-server:0.6.0`. Update with `docker compose pull && docker compose up -d`. A `stations.json` in your `config` folder picks up the new news names from the image's list by itself.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.
