# InterLude 0.9.0

Fixes and improvements from a review of the whole app: settings that now apply while playing, pause and seek in Earlier, faster starts, a station search, and a clearer path for stations InterLude is still learning.

## What's new

- **Earlier resumes and seeks.** Stop an earlier programme and Play carries on where you left off, on the Mac, the phone and the server. Tap the progress bar to move to any point. **Start again from the beginning** plays it from the top.
- **Faster starts.** Away from bulletin times, a live station starts playing at once and the analysis catches up behind you. Near a bulletin it still checks the last two minutes first, and the page now shows how far that has got.
- **Station search.** The station list has a search field that matches names and groups, so "york" or "scotland" finds a local station. With a mouse, you can just start typing.
- **Stations still being learned.** Radio 2, Radio 3 and now Radio Cymru 2 play their news while InterLude learns them. The player says so, lists the bulletins it has found, and after a couple offers **Start muting**.
- **Recent mutes lists what you heard.** Only bulletins you have reached that were muted, or that you put right, are listed. Talk the detector let go of by itself, and bulletins still a minute ahead, are left to the event log.

## Fixed

- Jingle only, the longest mute and the bulletin minutes changed in Settings now apply to what's playing at once, rather than at the next start.
- **Forget** on the news jingle no longer comes back. Before, the playing session still held the jingle and saved it again after the next bulletin.
- Changing a setting no longer risks writing over what InterLude has just learned about the station.
- The player stays responsive while audio is analysed, which now runs alongside serving the stream.

## Changed

- The shortest delay is now 60 seconds, up from 30. Talk that started near a bulletin time is let go after 45 seconds if no news jingle or newsreader is heard, and transcribing takes a few seconds more. With a shorter delay you would hear the start of that mute before it was taken back. A saved shorter delay is raised to 60 seconds.

## Changes for people who build or run it

- The speech rule is replayed in CI over labelled recordings in `Tests/Corpus` (Radio 1 and Radio 3, as classifier scores with no audio), and the tests fail if it does worse than the recorded figures. `Tests/Corpus/README.md` says how to add a recording.
- `stations.json` takes `"openings"` and `"signOffs"`, a station's own wording for the newsreader's opening and sign-off, added to the English ones. Radio Cymru 2 is marked `"untested": true`.
- The event log gains `lead` on each block (how many seconds ahead of the listener it was found) and on each release of presenter talk, plus `startLive` and `forgetJingle` events.
- What the Mac app and the server both did around a session (profiles, per-station settings, the Earlier schedule, resume points and the player's wording) now lives once in `InterLudeCore/Coordinator.swift`. Starting, stopping and the speakers are still each side's own.
- The web app's API gains `seek?f=`, `startover` and `startmuting`, and its state gains `startProgress`, `learning` and `resumeAt`.
- An unused detector flag, `suppressUntilMusic`, is gone.

## Before you install

- The Mac app needs macOS 26 or later on an Apple silicon Mac.
- Not notarised: the first time, allow it under System Settings › Privacy & Security › Open Anyway (steps in the README). Or build it from source.
- The server image is `ghcr.io/mstrtheplague/interlude-server:0.9.0`. Update with `docker compose pull && docker compose up -d`.
- Unofficial and not affiliated with the BBC. It relies on stream addresses the BBC doesn't document, which can change; the station list is editable if they do.
